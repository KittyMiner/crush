# Fleet Orchestration Agent Suite

This directory contains a specialized agent stack for fleet orchestration, calibration, optimization, coordination, health, compliance, research, and reporting.

Use these as project-level agent skills for a rigorous, evidence-driven workflow. Each agent is designed to operate independently but report upward to the fleet orchestrator.

Core rule: no speculation without evidence. Every recommendation must cite signals, logs, metrics, or code-level findings before action is taken.

Primary flow:
- Fleet orchestrator decides mission and scope.
- Sub-specialists collect evidence and diagnose.
- Optimization and calibration agents propose safe, minimal changes.
- Health, compliance, and reporting agents validate before final recommendation.
